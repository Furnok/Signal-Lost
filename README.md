# Signal_Lost

PREREQUISITES:   
- Operating System: Windows 10 or Later.
- Processor: 1 GHz.
- Memory: 128 MB RAM.
- Graphics Card: Minimum Resolution 1280x720px.
- Hard Disk: 10 MB of Available Space.

TERMS OF USE:   
PEGI 12 Warning, this game contains insults.

HOW TO DOWNLOAD:
- Download the Latest Version of the Release on GitHub.
- Unzip the folder ".zip".

HOW TO EXECUTE:
- Go to the Folder Build.
- Drag the text file "Chapter-(Number).txt" to the ".exe" to execute the program.

HOW TO USE:
- Tap on the number of the choice you want to make.
- Watch out, some choices have a timer attached to it on the down-right corner of the screen. If you don't make your choice in time, the game will choose a default answer.
- Your choice can raise or lower the confidence bar at the top of the screen. So try to keep it as high as possible, because you never know what might happen.
- Make sure your favorite web browser is running before you play. It might come in handy!
